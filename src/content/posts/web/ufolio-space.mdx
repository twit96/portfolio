<PostSection>

  ## Inspiration

  Ufolio.Space was born from the evolution of my own portfolio website. I built my first portfolio in 2020 with HTML, CSS, JavaScript, and jQuery, before rebuilding it in 2022 with the LEMP stack (Linux, Nginx, MySQL, and PHP).

  After refactoring that second iteration into a pseudo-MVC architecture, I realized that most portfolio websites could be distilled into a few common elements: contact info, projects, a resume, and skills.

  Rather than continuing to develop my portfolio website, I wanted to generalize its functionality into a platform for everyone.

</PostSection>
<PostSection>

  ## Content-Adaptive Design

  The central goal of Ufolio.Space was to separate content management from website design. I wanted users to be able to add and remove their info without having to worry about broken links, empty sections, and placeholder content.

  The application determines which sections to render based on the quantity and characteristics of the user's entered content. Users can curate and rank featured projects, while skill tags they assign to individual projects are automatically aggregated to generate skill rankings and categorized project listings.

  This eliminated the need for users to maintain a separate list of skills while allowing visitors to explore the projects that demonstrate each skill.

</PostSection>
<PostSection>

  ## Customization

  Instead of having a fixed set of page templates, Ufolio.Space has a composable theming system.

  Color palettes are stored as structured JSON in the database and translated into semantic CSS custom properties. Each palette includes both light and dark mode definitions, so components adapt to visitors' chosen mode.

  Users can separately choose decorative CSS backgrounds for their portfolio too, allowing them to mix and match without changing the underlying portfolio structure.

</PostSection>
<PostSection>

  ## Technical Architecture

  Ufolio.Space was my first application built with Laravel. I intentionally developed it as a server-rendered monolithic application to focus on learning the framework.

  The application utilizes Laravel's MVC architecture, Eloquent ORM, Blade templates, route model binding, authorization policies, and filesystem abstraction.

  Each user receives a dedicated URL under the Ufolio.Space domain, with the ability to manage their personal info, projects, profile photos, resume, and theme preferences.

  The application was deployed to a DigitalOcean server provisioned/managed through Laravel Forge. This simplified infrastructure management for me (including the PHP runtime upgrade in response to the October 2026 PHP2Shell vulnerabilities).

</PostSection>
<PostSection>

  ## Retrospective

  After deploying Ufolio.Space in March 2023, I shifted my focus toward React and the broader JavaScript ecosystem, later rebuilding my personal portfolio using Astro and React later that year.

  Although development of Ufolio.Space did not continue as originally envisioned, the project remains a significant milestone in my progression as a developer, representing a transition from building individual websites to designing reusable, data-driven applications for multiple users.

</PostSection>
<PostSection>

  ## Future Direction

  Since developing Ufolio.Space, much of my development experience has shifted toward the Node.js ecosystem.

  However, I'd like to someday revisit Ufolio.Space and transition it to a decoupled architecture, with a standalone backend exposing a REST API to support multiple frontend deployments (web, mobile, desktop, smart fridge, whatever).

  Ultimately, I'd want to preserve the original intentions behind Ufolio.Space: allow users to focus on their work rather than website development and maintenance.

</PostSection>
