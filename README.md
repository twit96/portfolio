# Personal Website

My personal website and portfolio. An enjoyable source of endless scope creep as I change my mind on features and architectural decisions.

## Built With

- [Astro](https://astro.build/) - Web framework
- [React](https://react.dev/) and [Fuse.js](https://www.fusejs.io/) - Search functionality
- [Google Cloud Storage](https://cloud.google.com/storage) - Image hosting
- [Netlify](https://www.netlify.com/) - Hosting and deployment

## Getting Started

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

The website should be available at [http://localhost:4321/](http://localhost:4321/).
